# 旧媒体季度修复助手

用于扫描已经进入 Emby 元数据目录、但被错误压成单季的电视剧/动画。

- 扫描：只读，不修改文件。
- 绿色：当前绝对集数从 1 连续到 N，且 N 与 TMDB 各正常季集数总和完全相等，可单个或批量修复。
- 黄色：存在异常但无法证明唯一映射，只显示问题，禁止自动修改。
- 修复：暂时停止 Symedia，经 CloudDrive2 在同一网盘内移动并重命名真实视频及同名元数据，然后删除旧的本地元素并重新生成 STRM/NFO/图片目录。
- 回滚：每次修复前保存本地元素 tar 备份和云端移动清单，面板中可回滚网盘名称与本地元素。
- 防误触：必须先完成只读预览，30 分钟内才能执行对应的单项或批量网盘修复。

修复后需在 Emby 扫描对应媒体库。MoviePilot 插件和 Emby 侧修复端使用独立长随机密钥通讯。
