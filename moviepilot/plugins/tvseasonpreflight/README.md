# 入库前动漫自动分季

0.2.0 起使用与“旧媒体季度修复助手”一致的独立卡片界面，提供真正控制整理引擎的启停开关，以及成功/安全跳过日志弹窗和表格。

执行时机是 MoviePilot 下载完成后、生成整理目标路径时：先收集整包并严格核对 TMDB 季度，再生成正确的季度目标路径，最后才移动或上传。程序直接使用当前整理任务已有的源路径和目标路径，不需要另外设置下载目录或上传目录，也不会原地改名做种文件。

这是 MoviePilot 中可见的管理插件，显示自动分季引擎状态、规则及处理日志。

真正的改名必须发生在 MoviePilot 生成整理目标路径之前，因此执行引擎仍位于
`/app/app/chain/transfer.py`。管理插件不会在下载完成后再次搬动或修改做种源文件。

流程：`下载完成 -> 核对整包与 TMDB -> 生成 Season/SxxExx 目标 -> 移动上传`。

只有连续、无重复、全部为 S01 绝对集号，且总数与 TMDB 正常季度总数完全相等的
全集包才会自动分季。其余情况记录为安全跳过。
