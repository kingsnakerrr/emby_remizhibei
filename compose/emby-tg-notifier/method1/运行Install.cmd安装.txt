JAV频道点播 15.7
方法1：浏览器打开，不常驻

【安装】
先安装 PotPlayer，完整解压本安装包，进入本文件夹，双击 Install.cmd。
工具自动寻找播放器；找不到时请选择 PotPlayer 安装目录里的 PotPlayerMini64.exe。
本文件夹不包含播放器本体。可右键桌面 PotPlayer 快捷方式，打开文件所在的位置查找。
Windows 安全提示请先核实来源，不要关闭全局安全防护。

【使用】
私聊通知机器人绑定 Emby 账号。频道点击 PotPlayer，再点私聊的打开按钮。
浏览器首次可能要求允许打开 JAV频道点播；组件首次还会要求确认通知服务器地址。
HTTP 地址没有传输加密，优先使用管理员配置的 HTTPS 地址。
播放时自动读取绑定用户的 Emby 续播位置；每约10秒以及退出时回写位置。
不常驻、不添加开机启动、计划任务或系统服务。仅本次播放期间运行同步组件。
本组件不是 Chrome/Edge 扩展，而是 Windows 浏览器跳转协议组件。
安装后请重新从频道获取播放按钮，旧私聊消息约10秒删除。

【身份与记录】
使用点击按钮者的 Telegram ID，匹配机器人已绑定的 Emby 用户 ID。
每次开始播放及同步时向 Emby 核验该用户，不按昵称猜测，不使用管理员身份充当观看用户。
用户被删除、禁用、禁止播放或重新绑定后，旧会话不能继续写回。
记录指 Emby 最近播放时间、播放次数、续播位置，以及观看至95%后退出标记已播放。
并不保证第三方 Playback Reporting 插件统计观看时长，也不创建原生客户端在线会话。
只有成功读取到真实播放位置才产生记录；打开失败、只点击按钮不算观看。
快进/回退按实际位置回写；退出时保留最后一次读到的位置，通常有约0.5秒采样误差。
断网或断电可能丢失最后一段进度，已有成功同步位置不会被伪造为0。
播放期间不要在同一个窗口改播其他视频；本组件只跟踪其专门打开的窗口和影片标识。
本版一次只允许一个频道播放。关闭播放器后再点另一部。

【查看状态】
安装位置：%LOCALAPPDATA%\JAV-Channel-Player
打开其中的 status.txt 查看最近一次同步结果，不含完整播放链接或账号密钥。

【更新】
下载新版包，完整解压；关闭正在进行的频道播放，等同步结束后重新运行 Install.cmd。
程序文件覆盖升级，保留播放器路径和已信任的服务器地址，不删除 Emby 数据或 TG 绑定。
从方法2切换本方法会停止并撤销电脑后台配对、移除登录自启，恢复浏览器播放。

【卸载】
先关闭播放器并等待同步完成。
在 Windows 设置 → 应用中卸载“JAV频道点播”，或运行本文件夹 Uninstall.cmd。
开始菜单也有 JAV频道点播 - Uninstall。
卸载移除本组件、启动项、配对凭据及协议关联，不卸载 PotPlayer，不删服务器 data 或播放记录。
老的15.6纯跳转工具使用另一安装目录，可另外运行老包的 Uninstall.ps1 移除旧关联。

【隐私】
安装包不含服务器账号、密码或 API Key。播放授权按 TG 用户、影片及有效期限定。
播放器最终仍收到带 Emby API Key 的媒体 URL，播放器/浏览器历史可能保存它。
请勿分享完整播放链接、浏览器跳转地址或播放器历史；本版不代表彻底的媒体凭据隔离。
