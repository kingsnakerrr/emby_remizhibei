JAV频道点播 15.7
方法2：安装后台常驻软件

【安装与配对】
先安装 PotPlayer，完整解压本包，进入本文件夹，双击 Install.cmd。
工具自动寻找播放器；找不到时选择 PotPlayerMini64.exe。
首次安装时，在通知机器人私聊发送 /pc，复制机器人给出的完整配对地址，粘贴到安装窗口。
如果绑定了多个服务器，请发送 /pc 服务器编号；机器人会提示编号。
配对地址有效期5分钟、仅一次使用，相当于配对口令，不要发给别人。
HTTP传输未加密，建议管理员配置HTTPS；如果仍使用HTTP，安装窗口会要求明确确认。
完成后托盘出现“JAV频道点播”。每个Windows登录用户只运行一个接收程序，不需管理员权限。

【使用】
这台电脑在线、托盘程序运行且空闲时，点击 TG 频道的 PotPlayer，即由配对电脑直接播放。
不需要浏览器中转，也不必再点私聊播放按钮；浏览器方法作为电脑离线时的备用入口。
电脑忙时会提示先关闭当前影片；电脑离线不会悄悄排队，联网后也不会自动补播旧点击。
服务端最多保留60秒的已派发任务，客户端取走一次；启动失败请重新点击。
先根据点击者TG ID找到Emby绑定，再把任务交给该绑定对应的电脑。
别人点击不会使用你的电脑或你的Emby用户；每个TG账号在每台Emby服务器只配对一台电脑。
同一账号重新配对会撤销旧电脑。更换TG绑定后需重新配对。

【进度与记录】
和方法1使用同一进度同步组件：读取Emby续播位置、约10秒回写一次，关闭时再回写。
每次播放和回写时实时向Emby核验绑定用户是否存在、启用且允许播放。
记录为最近播放时间、播放次数、续播位置；看到95%后退出标记已播放。
不是Emby原生播放器会话，不保证第三方Playback Reporting观看时长统计或控制台“正在播放”。
退出时约有0.5秒采样误差；断网断电保留最近成功上传的位置，不保证最后一秒不丢失。
打开失败或无法读取PotPlayer位置不伪造观看记录。
不要在同一播放窗口改播其他影片；关闭当前播放器后再点下一部。

【后台与控制】
此方法明确安装后台接收程序，并为当前Windows用户添加“登录时启动”。
不安装系统服务或管理员级计划任务，也不在电脑开放HTTP监听端口。
配对密钥使用Windows当前用户的DPAPI加密保存，不存储TG机器人Token或Emby密码。
托盘右键Status查看同步状态，Exit退出接收；正在播放时退出会等本次播放结束和同步完成。
也可以在开始菜单运行JAV频道点播 - Start / Stop。
Stop.cmd停止当前接收程序，保留登录自启；Start.cmd重新启动。
机器人发送 /pc_off 可立即撤销电脑授权并恢复浏览器入口。

【更新与重新配对】
下载新版安装包，完整解压，关闭频道播放后重新运行本方法Install.cmd即可覆盖升级。
同方法更新保留播放器路径和配对凭据，不需要每次重新配对。
需要换服务器、换账号或凭据已撤销时，运行RePair.cmd并取得新的 /pc 配对地址。
从方法1切换到方法2时按首次配对步骤操作；无需先卸载。

【卸载】
先关闭播放器，等同步完成。
在Windows设置 → 应用中卸载“JAV频道点播”，或双击Uninstall.cmd。
卸载停止接收程序、撤销服务器设备授权、删除登录自启、协议关联、快捷方式及本地程序配置。
若卸载时离线，会提示再向机器人发送 /pc_off 撤销服务端授权。
不会卸载PotPlayer，不删除Emby服务器data、TG账号绑定和观看记录。

【状态与隐私】
安装目录：%LOCALAPPDATA%\JAV-Channel-Player，status.txt显示最近同步结果。
播放地址最终会交给PotPlayer，媒体URL仍含Emby API Key；播放器历史可能保留，请勿分享。
安装包本身没有服务器地址、账号密码或API Key。不把编码当加密。
