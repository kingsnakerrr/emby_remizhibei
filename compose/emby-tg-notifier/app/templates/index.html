当前服务器 Webhook

这个地址要填写到 {{server['name']}} 的 Emby 后台 Webhook 中，事件选择“媒体库 → 已添加新媒体 / New Media Added”。 一台 Emby 的多个媒体库、多个 Telegram 通知任务都共用这一条 Webhook，程序收到后再按媒体库分流。
Emby 请求内容类型
v7 同时支持 application/json 和 multipart/form-data。 如果你的 Emby 下拉框可以选 application/json，推荐选 JSON；保持 multipart/form-data 也可以。 “发送测试通知”会被识别为 system.notificationtest；页面会自动显示最近一次 Webhook 状态。是否同步发送 Telegram，可在上方服务器设置中选择。

怎么选？
同一台 VPS + 同一 Docker 网络 → 复制“本机 Docker 内网地址”。
不同服务器 / 不同 Docker 网络 / 走反代域名 → 复制“公网 IP / 域名地址”。
不建议在 Emby Docker 里使用 127.0.0.1:8787，因为它指向 Emby 容器自己。
